  • The classifier learns only from the knowledge base examples.
  • The dev split chooses the confidence threshold; the test split was frozen and committed before any evaluation code existed.
  • Simulated customers draw their messages from the test split and add typos, filler words and order numbers at random, with a fixed seed.
  • A conversation counts as resolved only when the bot answered the main question; a confident wrong answer is counted as a failure, not as a success.
